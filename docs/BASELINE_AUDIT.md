Audit date: 20 July 2026
Result: baseline repository approved for continued development

## Repository coverage

The consolidated repository contains 136 source-controlled files after build
caches and generated bytecode are excluded. The audit covered:

- 41 application Python modules.
- 16 automated test modules.
- Four active Qt Designer forms.
- Six canonical popup SVG references.
- 21 PNG assets and both asset manifests.
- All skin JSON, packaging metadata, dependencies and migration code.
- The PyInstaller specification, hook, Windows builder and Inno Setup script.
- The GitHub Actions Windows workflow, installation guide and current README.

Every Python file parses and compiles. Every JSON and UI/SVG XML file parses.
Manifest SHA-256 values match the bundled canonical assets. No merge-conflict
markers or active v1.0.23 metadata remain.

## UI-baseline confirmation

- The active forms remain 720×58, 720×35, 720×261 and 720×164.
- Top bar, Prompt, Feedback, History, Answer and meeting-record corners are
  consistently 10 logical px; pill and circular status controls are unchanged.
- The centred logo is the only top-bar show/hide control.
- The top-bar profile shortcut and separate eye button are absent.
- The opacity button is fixed at x=640/y=20.
- Microphone and speaker artwork and their live level lamps are present at the
  approved positions.
- Plot and History remain mutually exclusive lower surfaces.
- History remains adaptive from one to four visible rows and smoothly scrolls
  further records.
- The validated main-popup model dropdown and three skin choices are present.

`docs\UI_BASELINE.md` is now the authoritative contract. Historical patch notes
are retained only as a record of previous releases. Obsolete version-specific
builder launchers were removed; `BUILD_INSTALLER.bat` and
`BUILD_UPDATE_V1.0.24.bat` both call the same canonical build script.

## Verification evidence

- 80 current cross-platform/static tests passed in the audit environment.
- The submitted Windows build log shows the pre-baseline application suite
  reached 100% before pytest failed during shared-Temp cleanup.
